# Boilerplate descriptions

Approved text for press, listings, event pages and partner pages that need to describe Hash Chain. Copy it as is, or shorten it. Do not add claims that are not here.

## Name and category

- **Name:** Hash Chain
- **Category:** the privacy Layer 0
- **Tagline:** Go in public. Come out private.
- **X handle:** `hashchainL0`
- **GitHub organization:** `HashChainL0`
- **Website:** https://hashchain.network

## One line

The private base layer for onchain finance.

## One sentence

Hash Chain is a privacy-first Layer 0 network: accounts, payments, swaps, assets and apps are private by default, settle in moments, and connect to Ethereum, Base, Robinhood Chain and Monero.

## Short paragraph

Public chains publish every balance, trade and counterparty forever. Hash Chain makes privacy a property of the base layer instead of an add-on. It is a network of its own, run by an independent validator set, where every account is shielded by default. Users can still prove what they choose, to whom they choose, with view keys and credentials. Private, not shady.

## Status line

Always say where the project stands when you describe it:

> Hash Chain is pre-launch and at the spec stage. Everything published so far is a draft design. Nothing is deployed or audited.

Drop this line only when that stops being true, and take the new wording from the [protocol spec](https://github.com/HashChainL0/protocol-spec), not from memory.

## Wording to avoid

- Do not call Hash Chain a bridge. Its links to other networks are called connections.
- Do not quote speeds, throughput, fees, prices, users or dates. The project has published none.
- Do not describe a design as built, audited or live.
- Do not write the name as HashChain, Hashchain or hash chain. See [Name](../README.md#name).
